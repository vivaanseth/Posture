# Upright 0.7.0

This release delivers the finalized Upright v2 interface and keeps the existing local posture-tracking engine intact.

## Highlights

- Finalized v2 desktop experience with a compact dark navigation rail, warm main surface, redesigned Today, History, Camera, Settings, reset confirmation, and onboarding screens.
- Live Today screen focused on whether you are within your comfortable baseline, with redesigned posture visualization, session trace, nudge count, and recovery states.
- OpenCV frame preprocessing now sits before MediaPipe for camera frame handling, resizing, and efficient preprocessing while MediaPipe remains responsible for pose landmark detection.
- Reminder behavior now reaches the reset state for sustained full hunching, and fresh profiles have reminder sound enabled by default.
- History, camera, calibration, settings, and onboarding continue to use local session, calibration, preference, and camera data without replacing existing posture logic.

## Upgrade notes

- Upright remains local-only. Camera frames continue to be processed on device and are not uploaded by the app.
- Existing settings, calibrations, session history, and exports remain compatible with the current local data model.
- Users who previously turned reminder sound off will keep that preference. Fresh profiles start with reminder sound on.
- The app remains beta software while real-hardware compatibility, performance, accuracy, signing, and notarization evidence continues to be collected.
