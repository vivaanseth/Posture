# Upright 0.8.0

This release completes the Upright rename across packaged application identity and project documentation.

## Highlights

- Upright is now used across the app ID, packaged Linux identity, application protocol origin, local data directory, export metadata, verification scripts, release notes, and documentation.
- Legacy visible product-name references have been removed from repository documentation.
- The existing posture tracking, OpenCV preprocessing, MediaPipe landmark detection, calibration, reminders, local settings, and v2 interface remain intact.

## Upgrade notes

- The local data directory is now `upright-desktop`.
- This is an identity cleanup release on top of the v2 interface and OpenCV-enabled tracking pipeline.
